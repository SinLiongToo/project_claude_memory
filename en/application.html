Applications: different systems want different memory

Servers want capacity and reliability, phones want low power, graphics cards want bandwidth per chip, AI accelerators want bandwidth per watt and per mm², and SSDs want low cost per GB. Even with the same DRAM or NAND inside, interfaces and packaging make completely different trade-offs for these goals.

Why they differ: DDR runs long PCB traces to multiple DIMM slots, which caps the per-pin rate. GDDR connects point-to-point to one GPU, so the per-pin rate can be pushed very high. HBM sits on a silicon interposer next to the GPU with traces only millimetres long, so it can use an extremely wide bus at a modest per-pin rate, reaching the highest total bandwidth and the best energy per bit (a few pJ/bit, a fraction of DDR).

Bandwidth math

Peak bandwidth (GB/s) = per-pin rate (Gb/s) × bus width (bits) ÷ 8
  • One DDR5-6400 DIMM: 6.4 × 64 ÷ 8 = 51.2 GB/s; an 8-channel server ≈ 410 GB/s.
  • HBM3E 9.6 Gb/s × 1024 ÷ 8 ≈ 1.23 TB/s; a GPU with 8 stacks ≈ 9.8 TB/s.
  • GDDR7 32 Gb/s × 32 ÷ 8 = 128 GB/s; a 384-bit card (12 devices) ≈ 1.5 TB/s.

Usable bandwidth is typically only 70–90% of peak after refresh, bank conflicts, read/write turnaround and row misses.

AI and the memory wall

For two decades processor compute has grown much faster than memory bandwidth. The gap is called the memory wall, and large language models make it especially visible.

Why LLM inference is bandwidth-bound

Generating each token reads every model weight from memory once, but each weight is used for only one multiply-add. At small batch sizes arithmetic intensity (FLOPs per byte) is very low, and the GPU spends most of its time waiting for data:

token/s ceiling ≈ memory bandwidth ÷ bytes read per token

Example: 70 billion parameters in FP16 (2 bytes) → 140 GB of weights. On 3.35 TB/s of HBM3, the batch-1 ceiling is about 3350 ÷ 140 ≈ 24 tokens/s. 8-bit quantization halves the bytes read and roughly doubles the ceiling. That is why the number of HBM stacks, their bandwidth and their capacity decide how competitive an AI accelerator is.

KV cache

Attention keeps Key/Value vectors for every previous token. Their size grows with context length × batch × layers and, for long contexts, can exceed the weights. This drives higher-capacity HBM (12- and 16-high stacks), offloading KV cache to CPU or CXL memory, and KV-cache quantization.

The roofline model

Achievable performance = min(peak compute, bandwidth × arithmetic intensity). Below the ridge point (“peak compute ÷ bandwidth”), more bandwidth helps more than more compute.

HBM system integration

  • Stack: 8–16 DRAM core dies connected vertically by TSVs on top of a base (logic) die. The base die holds the PHY, test logic and TSV repair; from HBM4 it is made on a foundry logic process and can be customized.
  • 2.5D packaging: the GPU and HBM sit side by side on a silicon interposer (e.g. CoWoS-S) or an organic / bridge interposer, with thousands of micro-bump connections only millimetres long.
  • Challenges: heat (DRAM dislikes heat but sits next to a GPU burning hundreds of watts), stack yield (one bad die ruins the stack, hence KGD testing), interposer capacity and warpage. See Test & packaging.

SSDs: the controller turns NAND into a drive

NAND has three awkward properties: no in-place overwrite (a whole block must be erased first), limited write endurance, and a high error rate. The SSD controller hides all of them and presents a drive that can read and write any address freely.

The FTL (flash translation layer)

  • Logical-to-physical mapping (L2P): every host write to a logical block address (LBA) goes to a fresh page and the old page is marked invalid. The table is usually kept at 4 KB granularity, needing about 1 GB of DRAM per 1 TB; DRAM-less SSDs use the host memory buffer (HMB) or partial caching.
  • Garbage collection (GC): when free blocks run low, pick a block with many invalid pages, move its valid pages away, then erase the block.
  • Write amplification (WAF): GC moves make NAND write more than the host asked. WAF = NAND bytes written ÷ host bytes written; with random writes and little free space it can exceed 3–5.
  • Over-provisioning (OP): capacity reserved from the user (e.g. 7%, 28%) makes GC more efficient and lowers WAF. Enterprise SSDs reserve more.
  • Wear leveling: spread writes across all blocks so hot data does not wear out a few blocks first.
  • TRIM: the OS tells the SSD which LBAs were deleted so GC need not move them.
  • SLC cache: writes land first in TLC/QLC blocks used in SLC mode — fast — and are folded into TLC/QLC when idle. Once the cache fills, write speed drops noticeably.
Micron note　Micron’s data-center SSDs include both high-performance TLC (PCIe Gen5) and high-capacity QLC lines, matching the trade-off in this section: TLC for performance and endurance, QLC for cost per TB and capacity density, suited to read-heavy AI data lakes and cold data.(Compiled from public sources, not official; see Micron’s own announcements for details.)

Endurance metrics

TBW ≈ capacity × P/E cycles ÷ WAF　　DWPD = TBW ÷ (capacity × warranty days)

Example: 2 TB TLC, 3000 P/E cycles, WAF 2.5 → TBW ≈ 2 × 3000 ÷ 2.5 = 2400 TB; over a 5-year warranty DWPD ≈ 0.66.

Phones and consumer devices

  • LPDDR: saves power with low-voltage I/O (0.5 V and below), deep standby modes (deep sleep, partial-array self refresh) and narrow channels; often placed as PoP (on top of the SoC) or inside the SoC package.
  • UFS: the phone storage interface. UFS 4.0 reads sequentially at about 4 GB/s using full-duplex serial links (MIPI M-PHY) and command queues, replacing eMMC.
  • uMCP: LPDDR and UFS in one package to save board area; common in mid-range phones.

Embedded and automotive

MCU code has long lived in embedded flash (eFlash). But floating gates are hard to integrate with HKMG processes below 28 nm, so the industry is moving to emerging NVM integrated in the back end:

  • eMRAM: in production at 22 nm and similar nodes; fast writes and high endurance, suited to automotive MCUs and IoT.
  • ePCM: used in 28 nm FD-SOI automotive MCUs.
  • eReRAM: low cost and very CMOS-friendly; used in IoT and low-power MCUs.

Extra requirements for automotive memory:

  • Temperature grade: AEC-Q100 Grade 1 (−40 to 125 °C) or Grade 2 (−40 to 105 °C). DRAM needs more frequent refresh when hot; NAND retention worsens.
  • Functional safety: ISO 26262 requires ECC, error reporting, address / command parity and BIST.
  • Long life and zero-defect targets: vehicles stay on the road 15+ years, so screening and burn-in are stricter (defect rates in ppm or even ppb).
  • Applications: ADAS and autonomous-driving domain controllers use LPDDR5/5X, GDDR, even HBM; infotainment uses UFS / eMMC; event data recorders need high-endurance SLC.

CXL, memory pooling and processing in memory

  • CXL (Compute Express Link): a cache-coherent protocol on the PCIe physical layer. CXL.mem lets a CPU use extra DDR on add-in cards or E3.S modules, breaking the DIMM-slot limit, at about 100 ns or more of extra latency. CXL 2.0/3.x supports memory pools shared by several hosts (pooling / sharing) to raise data-center memory utilization.
  • PIM (processing in memory): simple compute units (e.g. MACs) next to DRAM banks run GEMV-type work inside the memory, saving the energy of moving data. HBM-PIM and GDDR6-AiM prototypes exist.
  • CIM (computing in memory): uses the array itself for analog or digital multiply-accumulate, e.g. SRAM CIM or ReRAM crossbars, mainly for edge AI inference.

Glossary

DIMM / RDIMM
Dual in-line memory module / a server module with a registering clock driver (RCD).
PAM3 / PAM4
Modulation with 3 / 4 voltage levels per symbol, carrying 1.5 / 2 bits per symbol.
Memory wall
The bottleneck created by compute growing faster than memory bandwidth and latency.
Arithmetic intensity
Operations per byte read; decides whether code is compute- or bandwidth-bound.
KV cache
Key/Value tensors of previous tokens kept during transformer inference.
CoWoS
TSMC’s 2.5D packaging that integrates logic and HBM side by side on an interposer.
FTL
Flash translation layer: the SSD firmware layer handling mapping, GC and wear leveling.
WAF
Write amplification factor: NAND bytes written ÷ host bytes written.
OP
Over-provisioning: capacity reserved from the user.
TBW / DWPD
Total bytes written / drive writes per day — SSD endurance metrics.
HMB
Host memory buffer: a DRAM-less SSD borrows host memory for its mapping table.
UFS
Universal Flash Storage, the mainstream phone storage interface.
AEC-Q100
The automotive IC stress-qualification standard that defines temperature grades.
CXL
Compute Express Link, a cache-coherent interconnect on PCIe.
PIM / CIM
Computing next to / inside the memory array.

Interface specs keep moving with each speed bin; follow JEDEC standards and vendor announcements.
