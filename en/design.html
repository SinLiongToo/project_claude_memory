Chapter 2 · Circuit design

Design: organizing billions of cells

The cell is only the start. A 16 Gb DRAM has 17 billion cells. It must find one of them in tens of nanoseconds, amplify a signal of only about 100 mV, ship it off-chip at several Gb/s per pin, and guarantee correct data even though cells leak and break. This chapter covers the peripheral circuits that make that possible.

Array organization: chip → bank → mat

Put too many cells on one bit line and CBL swamps the signal; make a word line too long and its RC delay is too slow. So the array is split into a hierarchy:

  • Bank: an independently activatable array. Banks can be interleaved — one precharging while another reads — to hide latency. From DDR4 on, banks are grouped into bank groups, with different command spacing within and across groups (tCCD_L vs tCCD_S).
  • Row / page: one ACTIVATE loads a whole row (e.g. 1 KB for an x8 device) into the sense amps — a page. Further reads and writes to that row are fast (row hit); a different row needs precharge and activate (row miss).
  • Hierarchical word lines: a main word line (MWL, thick low-resistance metal) spans the bank, and at each mat an SWD generates the local word line, balancing speed and area.
  • Hierarchical data lines: bit line → local I/O (LIO) → global I/O (GIO) → read/write amplifiers in the chip center.

In an open architecture the edge mats have reference bit lines on one side only, so the array ends need extra dummy mats — one source of lost array efficiency.

The sense amplifier

A DRAM bit-line sense amplifier (BLSA) is essentially two cross-coupled inverters (much like an SRAM cell) between BL and BLB, using positive feedback to amplify a tiny difference to full swing. One read:

  1. Equalize and precharge (EQ): short BL and BLB together at VBLP = VDD/2.
  2. Word line on: the word line rises to VPP (above VDD, around 2.5–3 V, because the access transistor’s Vt is high and a full “1” must be written and read). Charge sharing creates ΔV.
  3. Fire the SA: first pull the NMOS common node down (SAN→0), then the PMOS common node up (SAP→VDD); the bit lines split to 0 / VDD.
  4. Restore and output: with WL still on, the amplified voltage is written back into the capacitor; when the column select (CSL) opens, data goes to the LIO.
  5. Precharge: turn WL off, equalize again, ready for the next activate.

The key figure is offset: Vt mismatch between the two halves of the SA creates a fixed input offset, and if ΔV is smaller than the offset the read is wrong. Advanced DRAM uses offset-cancellation SAs that first sample their own offset onto the bit lines and then sense.

SRAM typically uses a voltage latch SA, fired (SAE) only after the bit lines have developed 50–100 mV. The timing is tracked by a replica bit line so the SA fires when the signal is sufficient across PVT corners.

The sensing signal budget

The ΔV from charge sharing is only the ideal value. A design subtracts everything that eats into the signal; what remains is the real margin. An illustrative budget (VDD = 1.1 V, Cs = 10 fF, CBL = 50 fF):

Numbers are illustrative, to show the budgeting mindset. Real designs evaluate every line at each PVT corner with Monte Carlo.

The table shows why DRAM scaling is so hard: Cs cannot grow much each generation while CBL and offset do not shrink by themselves, so margin gets nibbled away. The Spec Designer’s “sense margin” subtracts only SA offset — the most optimistic estimate.

Interestingly, from DDR to DDR5 the data rate rose more than tenfold, but tRCD, CL and tRP in nanoseconds barely moved (they have stayed around 13–18 ns) because they are limited by the analog physics of the array. Bandwidth gains came mainly from the interface and parallelism.

Taking tRCD apart

tRCD of about 13–16 ns looks like one number, but it is a chain of analog events that must finish in order:

StageApprox. timeLimited by
Command decode, row address to the bank1–2 nsPeriphery logic speed, long wires
Main word line → sub word line rising to VPP2–4 nsWord-line RC, SWD drive, VPP pump
Charge sharing2–3 nsAccess-transistor on-resistance × (Cs+CBL)

Margin before column select may open2–3 nsPVT variation, guard time for the slowest mat

So a faster tRCD needs shorter word lines (more SWDs → area), stronger SAs (bigger → area) and higher VPP (reliability). That is why “low-latency DRAM” (RLDRAM, some low-tRCD server parts) trades area for speed.

I/O interfaces and prefetch

The array runs at only a few hundred MHz while the interface runs at several Gb/s. The answer is prefetch: each internal access fetches n times the I/O width at once, and a serializer (SERDES) streams it out at high speed.

Internal supplies and charge pumps

Externally DRAM gets only VDD and VDDQ (plus VPP from DDR4 on), but inside it needs several voltages made by regulators and charge pumps:

VPP2.5–3 VWord-line high so the access transistor turns fully on

VARY / VBLH~1.0 VArray high (the voltage of a written “1”)

VDDQ1.1 V (DDR5), 0.5 V (LPDDR5X)I/O
  • Pump peak current: every ACT charges thousands of bit lines and a whole word line. Several banks activating together make VPP droop — the reason tRRD and tFAW exist.
  • Trim: process variation pushes internal voltages off target; they are measured at test and corrected with fuses (see DFT below), so every die has its own settings.
  • Power-up sequence: internal supplies must settle and fuses (repair addresses, trims) be read before commands are accepted. Wrong order or timing can load bad repair data and cause failures that appear “only sometimes at boot”.
  • Refresh and self-refresh current (IDD5, IDD6) also comes from these supplies; low-power designs shut down unneeded pumps in standby.

Refresh

  • Auto refresh (REF): the controller issues a REF on average every tREFI (7.8 µs for DDR4, 3.9 µs for DDR5), and an internal counter picks which rows to refresh. During tRFC (about 300 ns for 16 Gb) those banks are unavailable.
  • Refresh overhead ≈ tRFC / tREFI. Higher density means longer tRFC and more overhead (about 7–8% for DDR5 16 Gb). DDR5 therefore adds same-bank refresh, locking only one bank per bank group while the others keep working.
  • Self refresh: in standby the DRAM refreshes itself from an internal oscillator so the controller can shut down the interface; LPDDR adjusts the refresh rate with temperature (TCSR).
  • High temperature: above 85 °C the refresh rate doubles, because retention falls exponentially with temperature.

Error correction (ECC)

  • SECDED Hamming: 64 data bits plus 8 check bits (72,64) correct one bit and detect two. The baseline for server ECC DIMMs.
  • Chipkill / SDDC: spreads codewords across chips so even a whole failed DRAM is correctable; used in data centers.
  • DDR5 on-die ECC: every 128 data bits get 8 internal check bits for single-bit correction (SEC), compensating for weaker cells and lower yield after scaling. It is transparent to the controller and does not replace system-level ECC.
  • NAND: the raw bit error rate (RBER) is far higher. Early controllers used BCH; today LDPC with soft-decision reads (several reads at different Vref to gather reliability information) corrects hundreds of bits per 1–4 KB.
  • SRAM: large caches also use SECDED and interleave physically adjacent cells into different codewords so one particle strike causing a multi-bit upset (MBU) stays correctable.

Redundancy and repair

A few dozen bad cells among billions is normal. Every mat reserves spare rows and spare columns. After test finds bad bits, fuses (laser fuses or electrical e-fuses / anti-fuses) record the bad addresses; every access is then compared against them and a hit is redirected to a spare line.

  • Redundancy analysis (RA): given the failing-bit pattern and a limited number of spare rows / columns, find an assignment that repairs every failure. This is NP-complete in general; in practice heuristics are used (must-repair first, then branch-and-bound).
  • PPR (post-package repair): DDR4/DDR5 let new bad rows be repaired after packaging, even in the system, with anti-fuses (hPPR permanent, sPPR temporary).
  • BISR: embedded SRAM uses MBIST to find failures and built-in analysis (BIRA) to allocate repair automatically.

The test and repair flow is detailed in Test & packaging.

DFT test modes and trim

To test billions of bits in reasonable time, DRAM has many factory-only test modes (entered with special command sequences):

  • Parallel test compression: write many bits or banks at once and compare on chip on read, reporting only pass / fail — far shorter test time, at the cost of address resolution, so a normal mode is used again to locate fails.
  • Forcing and monitoring internal voltages: route VPP, VBLP, VPLT etc. to a test pin to measure, or force them externally, to find the best trim and apply voltage stress.
  • Timing adjustment: shorten or stretch internal timings (SA fire time, WL pulse width) to find weak cells and measure margin.
  • Disabling ECC and repair: see raw failures so on-die ECC or redundancy does not hide problems — essential for yield analysis and screening weak cells.
  • Fuse trim: burn in trim values for internal voltages, timers and drive strength from the measurements.
  • Stress modes: e.g. a WL stress that turns on all word lines together, accelerating oxide weak spots during burn-in.
  • System-visible features: DDR5 / LPDDR5 define PPR, MBIST (on some products) and ECS (error check and scrub); the HBM base die provides an IEEE 1500 test interface.

SRAM macros and assist circuits

SRAM in an SoC is usually generated by a memory compiler: the designer specifies words × bits, column mux and ports, and the compiler outputs layout, timing models (.lib), a Verilog model and LEF. A macro contains the bitcell array, row decoders and word-line drivers, column mux (e.g. 4:1 or 8:1 so the SA fits the pitch), SAs, write drivers and timing control (a replica bit line).

Read and write assist

  • WL underdrive: lower the word-line voltage slightly during reads to weaken the PG and improve read stability (at some speed cost).
  • Negative bit line: pull BL below 0 (e.g. −100 mV) during writes to strengthen the PG.
  • Cell-VDD collapse: briefly lower the supply of the columns being written to weaken the PU.
  • Dual rails: the array runs on a higher, stable VDDM while logic runs on a scalable VDD, with level shifters in between.

Because a chip holds millions of bitcells, Vmin is set by the worst cells beyond 6σ, so SRAM yield analysis needs high-sigma statistical simulation (importance sampling and the like).

NAND chip design

  • Page buffer: a set of latches and sense circuits per bit line senses a whole page (16 KB) at once. Multi-level reads sense the same page at several VREAD levels in turn, and latch logic combines them into bits.
  • ISPP programming: the program voltage starts around 15 V and rises by ΔVPGM (a few hundred mV) per pulse, with a program verify after each. Cells that reach their target have their bit line raised to VDD to inhibit further programming. Smaller steps give narrower distributions but take longer.
  • Program inhibit (self-boosting): cells on the same word line that must not be programmed have their channels capacitively boosted to about 8 V, lowering the gate-to-channel field to avoid disturb.
  • Charge pumps: on-chip pumps generate VPGM, VPASS and erase voltages of 20 V and more.
  • Multi-plane: one die is split into 2–6 planes that read and program in parallel for more throughput.
  • Read retry / read calibration: when retention or disturb shifts the distributions, the controller rereads with another set of VREAD; newer chips can track optimal read levels automatically.

Design margin: PVT, statistics and aging

  • PVT corners: process (SS/TT/FF, NMOS and PMOS skewed separately), voltage (±5% or more), temperature (−40 to 125 °C by grade). DRAM worst cases differ by circuit: SA offset is worst cold, leakage worst hot, speed worst at low voltage and high temperature (but at low voltage it may flip to cold — see temperature inversion).
  • Statistical design: SA offset and SRAM bitcells must be judged at 6σ or even 7σ (the worst of billions of instances), needing Monte Carlo with importance sampling; designs checked only at typical values fail at the tails in production.
  • Aging margin: BTI and HCI shift Vt over time, so margin must be reserved for end of life — SRAM Vmin, for example, rises with use.
  • Power integrity: IR drop and dynamic droop (many banks active, simultaneous switching output, SSO) must be included in timing analysis.
  • Signal integrity: high-speed I/O needs channel simulation (reflections, crosstalk, ISI) and proof that training converges across DIMM / motherboard combinations.
  • ESD and latch-up: new I/O structures and thinner oxides make ESD protection harder; 2.5D products such as HBM must also survive CDM events during assembly.

Glossary

Bank / Bank group
An independently activatable array / a group of banks sharing some resources.
Page (DRAM)
The whole row loaded into the sense amps by one ACT; typically 1 KB for x8 devices.
Mat / Subarray
The smallest array block in a bank, bounded by SA rows and SWD columns.
SWD / MWL
Sub-word-line driver / main word line in a hierarchical word-line scheme.
VPP
Word-line high voltage above VDD so the access transistor turns fully on.
VBLP
Bit-line precharge voltage, usually VDD/2 in DRAM.
SA offset
Input offset of a sense amp caused by mismatch; ΔV must exceed it.
Row hit / miss
Whether the accessed row is already in the sense amps.
Prefetch
Reading several times the I/O width internally and serializing it out at high speed.
BL16
Burst length 16: one read or write transfers 16 beats.
DFE / CTLE
Decision-feedback / continuous-time linear equalization to compensate channel loss.
ZQ calibration
Calibrating output drive and termination impedance against a precision external resistor.
tREFI / tRFC
Average refresh interval / time each refresh command occupies.
SECDED
Single error correction, double error detection.
LDPC
Low-density parity-check codes, the mainstream ECC in NAND controllers.
PPR
Post-package repair of bad rows.
Memory compiler
A tool that generates SRAM macro layouts and models from parameters.
Column mux
Several bit lines sharing one SA.
Program verify
Checking after each program pulse whether Vt has reached its target.
Signal budget
The margin left after subtracting leakage, offset, coupling and other losses from the ideal ΔV.
VNWL / VBB
Negative word-line voltage / body bias that turns the access transistor off harder.
Charge pump
A circuit that makes voltages above or below the supply on chip.
Trim
Fuse-programmed adjustment of internal voltages or timing based on measurements.
Test mode
Factory-only modes such as parallel test compression and voltage monitoring.
PVT corner
Extreme combinations of process, voltage and temperature.
Self-boosting
NAND program-inhibit technique that couples up the channel of unselected cells.
