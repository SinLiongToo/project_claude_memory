應用：不同系統要的是不同的記憶體

伺服器要容量與可靠度，手機要省電，顯示卡要每顆晶片的頻寬，AI 加速器要每瓦、每平方毫米的頻寬，SSD 要每 GB 的成本。同樣是 DRAM 或 NAND，介面與封裝會為了這些目標做出完全不同的取捨。

Micron 註記　Micron 對應各介面的產品形態舉例：伺服器的 DDR5 RDIMM 與 MRDIMM（多工 rank，提高每通道頻寬）；筆電與手機的 LPDDR5X，以及可插拔的 LPDDR 模組 LPCAMM2；AI 伺服器用的 LPDDR 模組 SOCAMM；顯示卡的 GDDR6X（與 NVIDIA 合作、採 PAM4 訊號）與 GDDR7；AI 加速器的 HBM3E（8 層 24 GB、12 層 36 GB）與 HBM4；以及 CXL 記憶體擴充模組。（依公開資料整理，非官方資訊；細節以 Micron 官方公告為準）

差異的根源：DDR 走 PCB 上的長走線、要插多條 DIMM，所以每腳速率受限；GDDR 只點對點連一顆 GPU，可以把每腳速率推到很高；HBM 直接放在 GPU 旁的矽中介層上，走線只有幾毫米，可以用極寬的匯流排、較低的每腳速率，達到最高的總頻寬與最好的每位元能耗（約數 pJ/bit，DDR 的數分之一）。

頻寬怎麼算

峰值頻寬 (GB/s) = 每腳速率 (Gb/s) × 匯流排寬度 (bit) ÷ 8
  • DDR5-6400 一條 DIMM：6.4 × 64 ÷ 8 = 51.2 GB/s；8 通道伺服器 ≈ 410 GB/s。
  • HBM3E 9.6 Gb/s × 1024 ÷ 8 ≈ 1.23 TB/s；一顆 GPU 放 8 個堆疊 ≈ 9.8 TB/s。
  • GDDR7 32 Gb/s × 32 ÷ 8 = 128 GB/s；384-bit 顯示卡（12 顆）≈ 1.5 TB/s。

實際可用頻寬通常只有峰值的 70–90%：要扣掉 refresh、bank 衝突、讀寫切換（bus turnaround）、row miss 等開銷。

AI 與記憶體牆

過去二十年，處理器的運算能力成長遠快於記憶體頻寬，兩者差距被稱為記憶體牆。大型語言模型讓這個問題變得特別明顯。

為什麼 LLM 推論受限於頻寬

生成每一個 token 時，模型的所有權重都要從記憶體讀一次，但每個權重只做一次乘加。批次很小時，運算強度（FLOP / Byte）極低，GPU 的算力大多在等資料：

token/s 上限 ≈ 記憶體頻寬 ÷ 每個 token 要讀的位元組數

例：700 億參數、FP16（2 bytes）→ 140 GB 權重。在 3.35 TB/s 的 HBM3 上，批次 1 的上限約 3350 ÷ 140 ≈ 24 token/s。改用 8-bit 量化就讀一半的資料，上限約變兩倍。這就是 HBM 堆疊數、頻寬、容量直接決定 AI 加速器競爭力的原因。

KV cache

注意力機制要保存先前每個 token 的 Key/Value 向量，容量隨「上下文長度 × 批次 × 層數」線性增加，長上下文時甚至超過權重本身。這推動了更大容量的 HBM（12、16 層堆疊）、把 KV cache 卸載到 CPU 記憶體或 CXL 記憶體、以及 KV cache 量化等做法。

Roofline 模型

可達效能 = min(峰值算力, 頻寬 × 運算強度)。運算強度低於「峰值算力 ÷ 頻寬」這個轉折點時，提升頻寬比提升算力更有用。

HBM 系統整合

  • 堆疊：8–16 片 DRAM 核心晶粒以 TSV 垂直連接，疊在一片基底晶粒（base / logic die）上。基底晶粒負責 PHY、測試邏輯與 TSV 修補；HBM4 起改用晶圓代工的邏輯製程製作，可客製化功能。
  • 2.5D 封裝：GPU 與 HBM 並排放在矽中介層（如 CoWoS-S）或有機 / 矽橋中介層上，數千條微凸塊連線只有幾毫米長。
  • 挑戰：散熱（DRAM 怕熱，但旁邊是數百瓦的 GPU）、堆疊良率（一片壞全部壞，所以要 KGD 測試）、中介層產能、翹曲。詳見封測章節。

SSD：控制器讓 NAND 變成硬碟

NAND 有三個「不好用」的特性：不能覆寫（必須先整個 block 抹除）、寫入次數有限、錯誤率高。SSD 控制器把這些全部藏起來，對主機呈現成一顆可以隨意讀寫任何位址的硬碟。

FTL（Flash Translation Layer）

  • 邏輯→實體對照（L2P mapping）：主機寫入的邏輯位址（LBA）每次都寫到新的空白頁，舊頁標記為無效。對照表通常以 4 KB 為單位，每 1 TB 容量約需 1 GB DRAM；無 DRAM 的 SSD 用主機記憶體緩衝（HMB）或部分快取。
  • 垃圾回收（GC）：當空白 block 不足時，挑一個無效頁多的 block，把其中有效頁搬走，再抹除整個 block。
  • 寫入放大（WAF）：GC 搬移造成 NAND 實際寫入量大於主機寫入量。WAF = NAND 寫入量 ÷ 主機寫入量，隨機寫入、可用空間少時 WAF 可達 3–5 以上。
  • 預留空間（OP）：保留部分容量不給使用者（例如 7%、28%），讓 GC 更有效率、降低 WAF。企業級 SSD OP 較大。
  • 平均抹寫（Wear leveling）：把寫入平均分散到所有 block，避免熱資料把某些 block 先寫壞。
  • TRIM：作業系統告訴 SSD 哪些 LBA 已刪除，SSD 就不必在 GC 時搬移它們。
  • SLC 快取：先把寫入以 SLC 模式暫存在部分 TLC/QLC block，寫得快，閒置時再搬回 TLC/QLC。快取寫滿後速度會明顯下降。
Micron 註記　Micron 的資料中心 SSD 同時有高效能 TLC（PCIe Gen5）與大容量 QLC 產品線，正好對應本節的取捨：TLC 追求效能與耐寫，QLC 追求每 TB 成本與容量密度，適合讀取為主的 AI 資料湖與冷資料。（依公開資料整理，非官方資訊；細節以 Micron 官方公告為準）

壽命指標

TBW ≈ 容量 × P/E 次數 ÷ WAF　　DWPD = TBW ÷ (容量 × 保固天數)

例：2 TB TLC、P/E 3000 次、WAF 2.5 → TBW ≈ 2 × 3000 ÷ 2.5 = 2400 TB；5 年保固 → DWPD ≈ 0.66。

手機與消費性裝置

  • LPDDR：以低電壓 I/O（0.5 V 以下）、低功耗待機（deep sleep、partial array self refresh）、窄通道省電；常以 PoP（疊在 SoC 上方）或同封裝方式放置。
  • UFS：手機儲存介面，UFS 4.0 循序讀取約 4 GB/s，採全雙工串列（MIPI M-PHY）與命令佇列，取代 eMMC。
  • uMCP：把 LPDDR 與 UFS 放在同一封裝，節省主機板面積，常見於中階手機。

嵌入式與車用

MCU 的程式碼長期存在嵌入式 Flash（eFlash）。但 28 nm 以下的 HKMG 製程很難再整合浮閘，業界轉向後段整合的新興 NVM：

  • eMRAM：22 nm 等製程已量產，寫入快、耐寫，適合車用 MCU 與 IoT。
  • ePCM：用於 28 nm FD-SOI 車用 MCU。
  • eReRAM：成本低、與 CMOS 相容性好，用於 IoT 與低功耗 MCU。

車用記憶體的額外要求：

  • 溫度等級：AEC-Q100 Grade 1（−40～125 °C）或 Grade 2（−40～105 °C）；DRAM 高溫要更頻繁 refresh，NAND 高溫保存變差。
  • 功能安全：ISO 26262，需要 ECC、錯誤回報、位址 / 指令同位檢查、BIST。
  • 長壽命與零缺陷目標：車輛使用 15 年以上，篩選與老化測試更嚴格（以 ppm、甚至 ppb 計的不良率）。
  • 應用：ADAS 與自動駕駛域控制器使用 LPDDR5/5X、GDDR、甚至 HBM；資訊娛樂系統使用 UFS / eMMC；事件資料記錄需要高耐寫 SLC。
Micron 註記　Micron 是車用記憶體的主要供應商之一，產品涵蓋車規 LPDDR、NOR Flash、e.MMC / UFS 與車用 SSD。車用產品的溫度等級、長期供貨與功能安全要求，正是本節列出的重點。（依公開資料整理，非官方資訊；細節以 Micron 官方公告為準）

CXL、記憶體池與存內運算

  • CXL（Compute Express Link）：建立在 PCIe 實體層上的快取一致性協定。CXL.mem 讓 CPU 透過擴充卡或 E3.S 模組使用額外的 DDR，突破 DIMM 插槽數的限制；延遲比本地 DRAM 多約 100 ns 以上。CXL 2.0/3.x 支援多主機共用的記憶體池（pooling / sharing），提高資料中心的記憶體利用率。
  • PIM（Processing-in-Memory）：在 DRAM 的 bank 旁放簡單的運算單元（例如 MAC），讓 GEMV 類運算在記憶體內部完成，省下搬資料的能量。已有 HBM-PIM、GDDR6-AiM 等原型產品。
  • CIM（Computing-in-Memory）：直接利用陣列做類比或數位乘加，例如 SRAM CIM、ReRAM 交叉陣列，主要瞄準邊緣 AI 推論。

名詞解釋

DIMM / RDIMM
雙列直插記憶體模組 / 加了暫存時脈驅動器（RCD）的伺服器用模組。
PAM3 / PAM4
每個符號有 3 / 4 個電壓位準的調變，每符號傳送 1.5 / 2 位元。
Memory wall
運算速度成長快於記憶體頻寬與延遲改善造成的瓶頸。
Arithmetic intensity
每讀一個位元組做多少次運算，決定程式受限於算力還是頻寬。
KV cache
Transformer 推論時保存的先前 token 的 Key/Value 張量。
CoWoS
台積電的 2.5D 封裝技術，以中介層並排整合邏輯晶片與 HBM。
FTL
Flash Translation Layer，SSD 韌體中負責位址對照、GC、平均抹寫的層。
WAF
Write Amplification Factor，NAND 實際寫入量與主機寫入量之比。
OP
Over-Provisioning，不提供給使用者的預留容量。
TBW / DWPD
總寫入位元組數 / 每日全碟寫入次數，SSD 壽命指標。
HMB
Host Memory Buffer，無 DRAM 的 SSD 借用主機記憶體存放對照表。
UFS
Universal Flash Storage，手機主流儲存介面。
AEC-Q100
車用積體電路應力測試認證標準，定義溫度等級。
CXL
Compute Express Link，基於 PCIe 的快取一致性互連。
PIM / CIM
在記憶體旁 / 記憶體陣列內進行運算。
