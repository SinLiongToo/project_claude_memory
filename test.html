Chapter 5 · Test & packaging

封測：找出壞掉的位元、修好它、再把晶片疊起來

記憶體是測試最密集的半導體產品：每顆晶片的每一個位元都必須被寫入、讀出、在高低溫下驗證；壞的要找出來並修補，修不好的要淘汰。封裝則從單顆晶片走向十幾層的 TSV 堆疊，對已知良好晶粒（KGD）的要求越來越高。

測試流程總覽

  • WAT（Wafer Acceptance Test）：量切割道上的測試結構，確認製程參數在規格內，屬於製程監控。
  • CP（Chip Probe / Wafer Sort）：探針卡接觸每顆晶粒的焊墊，執行直流測試（open/short、漏電、IDD）與功能測試，輸出每顆晶粒的失效位元資料。
  • 修補：依失效位址決定備用列 / 行的配置，用雷射或電熔絲寫入，再重測確認。
  • FT（Final Test）：封裝後在 ATE 上全速測試，依可通過的速度與時序分級（speed binning）。

記憶體故障模型

測試不是隨便寫些資料再讀回來，而是根據可能的物理缺陷抽象出故障模型，再設計能涵蓋它們的測試序列。

March 演算法

March 測試由多個「March 元素」組成：每個元素依指定的位址順序（⇑ 遞增、⇓ 遞減、⇕ 任意）走過每一個單元，對每個單元依序執行一串操作（w0 寫 0、r1 讀並預期 1……）。複雜度與單元數 N 成線性，適合大容量記憶體。

March C−：{ ⇕(w0); ⇑(r0,w1); ⇑(r1,w0); ⇓(r0,w1); ⇓(r1,w0); ⇕(r0) }　→ 10N

為什麼這樣設計

  • 每個單元都被讀到 0 和 1 → 抓 SAF。
  • 每個單元都經歷 0→1 和 1→0 轉換，並在轉換後被讀 → 抓 TF。
  • 以遞增與遞減兩種順序走訪：對任一對單元，攻擊者總會在某個元素中「先」被操作，然後受害者「後」被讀取 → 抓各種方向的耦合故障。
  • 每個元素都先讀再寫，讀的值是上一個元素寫入的值；若位址解碼錯誤，會讀到不對的值 → 抓 AF。

修補流程與 KGD

  1. CP1 執行完整測試，記錄所有失效位元的位址。
  2. 修補分析（RA）：每個 mat 只有固定數量的備用列 / 行。若某列失效位元數超過備用行數，這列「必須」用備用列修（must-repair）；剩下的再以搜尋演算法分配。找不到解的晶粒判為不可修。
  3. 熔絲寫入：雷射熔絲（雷射燒斷金屬線，需要開窗、只能在晶圓上做）或電熔絲 / 反熔絲（電流熔斷或擊穿，封裝後也能寫）。
  4. CP2 驗證修補結果，並做低溫或保存測試。

KGD（Known Good Die）：要被堆疊或與其他晶片共封裝的晶粒，必須在晶圓階段就達到接近封裝後成品的品質，因為一片壞晶粒會拖累整個昂貴的堆疊。這讓晶圓測試必須涵蓋更多原本在 FT 才做的高速與溫度測試。

ATE 與測試成本

  • 平行度：記憶體 ATE 一次可測數百顆晶粒（CP）或數百顆封裝（FT），由測試機內建的演算法圖形產生器（ALPG）產生位址與資料序列。
  • 測試時間：容量越大、測試時間越長；保存測試需要等待，更是耗時。數十 Gb 晶片的完整測試可達數十分鐘到數小時。
  • 測試成本可達 DRAM 總成本的可觀比例，因此會用：晶片內建自我測試模式（DFT test mode，例如一次寫多個 bank、內部壓縮比較結果）、減少不必要的測試項目、提高平行度。
  • 直流測試：Open/Short（接觸）、輸入漏電、各種 IDD（IDD0 啟動電流、IDD2P 待機、IDD6 自我更新）。
  • 速度分級：同一批晶片依能穩定運作的最高速度與時序分成不同等級出貨。

Shmoo 圖與測試裕度

Shmoo 圖是把兩個條件（最常見是電壓與速度 / 時序）掃一遍，每個格子標示通過或失敗。它是特性分析（characterization）與除錯最常用的工具，因為形狀本身就透露失效機制。

  • 斜邊：電壓越高電晶體越快，所以通過區通常是「左上缺一角」的形狀，斜邊代表速度路徑。
  • Vmin 牆：低於某電壓，不論速度多慢都失敗，通常是 SA、SRAM 或保持電路的功能極限。
  • 高壓失效：高電壓端失敗，可能是漏電、熱載子、或某些電路在高壓下時序反而競爭（race）。
  • 洞：通過區中間零星的失敗，常是圖形相依、雜訊或邊際時序，需要換資料背景與重複量測確認。
  • 溫度反轉（temperature inversion）：先進製程在低電壓時，低溫反而比高溫慢（Vt 在低溫升高的影響超過遷移率提升），所以低壓的最差溫度可能是冷而不是熱。

Guard band 與測試相關性

測試機有量測誤差，測試條件也不可能和客戶系統完全一樣，所以測試限值（test limit）必須比規格（spec）更嚴格，這段差距就是 guard band：

測試限值 = 規格 − (測試機時序精度 + 溫度 / 電壓條件差 + 老化預留)

例：規格 tRCD = 13.75 ns，測試機邊緣定位精度 ±0.15 ns，再預留 0.15 ns 給溫度與老化，就以 13.45 ns 測試。

  • Overkill（誤殺）：其實符合規格、但沒通過較嚴的測試限值而被淘汰的晶片。Guard band 越大，overkill 越多，良率與營收越低。
  • Underkill / escape（漏網）：不符合規格卻通過測試而出貨。Guard band 太小、測試覆蓋不足、測試溫度不對都會造成。
  • 相關性（correlation）：不同測試機、不同測試站（CP vs FT vs SLT）、不同探針卡之間結果要一致。用 golden unit（已知特性的樣品）定期比對，並追蹤各站的良率差異。
  • 重測政策：失敗品重測後通過算不算良品？重測可以救回接觸不良造成的誤殺，但也可能讓邊際品混過去，所以要限制次數並分析重測通過率。
  • 統計指標：參數的 Cpk（製程能力）決定 guard band 的成本；Cpk 高的參數可以用較小的 guard band 而不增加漏網。

電壓測試：Vmin、Vmax、VLV、VHV

電壓是最便宜、也最有效的測試旋鈕。四種常見的電壓測試目的不同：Vmax 和 Vmin 是邊界測試，確認晶片在規格電壓範圍內正常；VLV 和 VHV 是篩選測試，故意跑到規格外，讓潛在缺陷現形。

測試條件（以標稱 1.1 V 為例）目的主要抓什麼
Vmax規格上限再加 guard band（如 1.155 V → 1.2 V），全速功能測試確認高電壓端正常漏電、高壓下的時序競爭（hold time）、對高壓敏感的電路
Vmin規格下限再減 guard band（如 1.045 V → 1.02 V），全速功能測試；特性分析時逐步降壓找出每顆晶片的實際 Vmin確認低電壓端正常、量出裕度慢速路徑、SA / SRAM 的功能極限
VLV
Very Low Voltage		遠低於規格（約 0.6–0.8 × 標稱，但仍高於健康晶片的 Vmin），通常放慢時脈做功能測試缺陷篩選電阻性橋接 / 開路、弱接觸孔、閘極氧化層短路等，在標稱電壓下被強驅動力掩蓋的缺陷
VHV
Very High Voltage		遠高於規格（約 1.3–1.5 × 標稱），施加毫秒到數秒的電壓應力，之後回到標稱電壓重測加速篩選（像縮短版的 burn-in）氧化層弱點、介電層缺陷等早夭失效

為什麼 VLV 抓得到標稱電壓抓不到的缺陷

  • 標稱電壓下電晶體驅動力強，一個幾 kΩ 的電阻性橋接或開路只讓延遲多一點，功能仍然正確。低電壓時驅動電流大幅下降，同樣的電阻佔延遲的比例變大，或讓節點電壓落在錯誤的邏輯準位，缺陷就現形了。
  • 這類缺陷常是可靠度缺陷：現在能動，但在現場會隨時間惡化（電遷移、腐蝕、熱應力），所以 VLV 篩選能直接降低出貨後的早期失效。
  • VLV 的電壓要選在「健康晶片全部通過、缺陷晶片會失敗」的位置。太低會誤殺健康但偏慢的晶片；通常依健康母體的 Vmin 分佈決定（例如高於平均值 4–6σ），並且放慢時脈。
  • 極低電壓測試（very-low-voltage testing）在 1990 年代由 Hao 與 McCluskey 等人提出，用來篩選弱 CMOS 元件。

VHV 應力怎麼做

  • 以標稱電壓的 1.3–1.5 倍施加短時間電壓（可以在晶圓測試時做），讓帶有缺陷的薄弱氧化層提早崩潰；之後以正常電壓、Vmin、VLV 重測，抓出被「轉換」成硬失效的晶片。
  • 電壓加速通常遠比溫度有效：介電崩潰時間對電場呈指數關係，幾秒的高壓可以取代很長的 burn-in，所以常用來縮短或取代部分 burn-in。
  • 風險是過度應力：電壓太高或時間太長，會傷害健康晶片，留下「可靠度負債」。電壓上限要依 TDDB 資料決定，並驗證應力前後健康晶片的參數沒有漂移。
  • DRAM 可以用測試模式對內部電壓單獨加應力：提高 VPP 對存取電晶體的閘極氧化層加壓、讓所有字元線同時開啟的 WL stress、提高電容上極板電壓對電容介電層加壓。

Vmin 的統計用法

  • Vmin 離群值：每顆晶片的實際 Vmin 是很靈敏的健康指標。同一批中 Vmin 明顯偏高的晶片，即使在規格內通過，也常帶有潛在缺陷，可以用 PAT 剔除（例如超過中位數 + 4σ）。
  • ΔVmin：在 burn-in 或 HTOL 前後量 Vmin，偏移量大的晶片代表正在老化或有缺陷，可用於篩選與可靠度分析。
  • Vmin 分級與 AVS：邏輯晶片常依 Vmin 分級，或在系統中做自適應電壓調整（AVS）；SRAM 的 Vmin 通常決定整顆 SoC 的最低工作電壓。
  • 溫度：Vmin 常在低溫最差（溫度反轉），所以 Vmin 與 VLV 測試要考慮在冷溫進行。

常見陷阱

  • 電源精度與壓降：低電壓時，幾十 mV 的誤差就佔很大比例。要在晶片腳位附近量測（remote sense），並注意大電流時的 IR drop。
  • VLV 的時序：低壓下速度變慢，如果沿用全速時序，會把健康晶片誤殺。
  • 只測規格角落：規格下限的 Vmin 測試幾乎抓不到電阻性缺陷，因為健康與缺陷晶片在規格內都通過——這正是 VLV 存在的理由。
  • 應力後沒有重測：VHV 之後一定要再跑功能測試，否則被轉換出來的失效會直接出貨。
  • 外部 VDD 與內部電壓：DRAM 內部有穩壓器，改變外部 VDD 不一定會改變陣列電壓，要用測試模式直接調整或監測內部電壓（見內部電源）。

嵌入式記憶體的 MBIST

SoC 裡的 SRAM 數以百計，無法從外部腳位直接存取。MBIST（Memory Built-In Self-Test）在每組記憶體旁加入控制器，由晶片內部產生 March 序列並比較結果，只把通過 / 失敗與失效位址送出。搭配 BIRA / BISR（內建修補分析 / 自我修補）可以自動配置備用元件，修補資訊存在 e-fuse 中，開機時載入。車用晶片還要求開機或執行期週期性執行 MBIST（in-system test）以符合功能安全。

組裝流程

  1. 晶圓研磨（Back grinding）：把晶圓從約 775 µm 磨薄到數十 µm（多晶粒堆疊需要很薄）。
  2. 切割（Dicing）：刀片切割、雷射開槽或隱形雷射切割（stealth dicing，在晶圓內部形成改質層再擴張分離，適合超薄晶圓）。DBG（先切後磨）可降低薄晶粒的崩邊與破裂。
  3. 黏晶（Die attach）：以晶粒黏著膜（DAF）固定在基板或下層晶粒上。
  4. 打線（Wire bonding）：金線或銅線連接晶粒焊墊與基板，多層堆疊時以階梯錯位或線上膜（FOW）方式打線。
  5. 模封（Molding）：環氧樹脂模封保護。
  6. 植球、雷射打印、切單（Singulation）。

HBM 堆疊與 TSV

  • TSV：在 DRAM 晶粒中蝕刻數千個直徑數 µm 的矽穿孔並填銅（通常在前段與後段之間製作，via-middle），研磨晶圓背面讓 TSV 露出，做背面凸塊。
  • 晶粒減薄：12 層堆疊加上基底晶粒要塞進 JEDEC 規定的封裝高度（HBM3E 為 720 µm，HBM4 放寬到 775 µm），每片核心晶粒只有約 30–50 µm 厚。
  • 堆疊與填充：
    • TC-NCF：每層之間放非導電膜，以熱壓鍵合逐層接合。
    • MR-MUF：先以回流焊一次接合所有層，再注入液態模封材料填滿縫隙，散熱與產能較佳。
    • 混合鍵合（Hybrid bonding）：沒有凸塊，Cu–Cu 直接接合，可縮小層間距與總高度，被視為 16 層以上堆疊的關鍵技術。
  • 測試挑戰：核心晶粒在堆疊前要做 KGD 測試；堆疊後要測 TSV 連通性，並用備用 TSV 修補；基底晶粒提供 IEEE 1500 測試介面與 MBIST。完成的堆疊（KGSD, Known Good Stacked Die）再交給 2.5D 封裝。
  • 散熱與翹曲：多層薄晶粒熱阻高，熱源 GPU 又在旁邊；不同材料的熱膨脹係數不同，會造成翹曲與接點應力。
Micron 註記　Micron 的製造網路（公開資料）：DRAM 前段晶圓廠主要在台灣（台中、桃園）與日本廣島，NAND 前段主要在新加坡；美國愛達荷州 Boise 與紐約州有新建 DRAM 晶圓廠計畫。後段封測據點包含台灣、馬來西亞檳城、中國西安與印度 Sanand。HBM 的先進封裝在台灣進行，並規劃在新加坡設立 HBM 封裝廠。（依公開資料整理，非官方資訊；細節以 Micron 官方公告為準）

Burn-in 與最終品質

浴缸曲線告訴我們：早期失效（infant mortality）來自製造中的潛在缺陷。Burn-in 在高溫（例如 125 °C）與高電壓下長時間操作晶片，加速這些弱元件提早失效，在出貨前把它們篩掉。記憶體常以晶圓層級 burn-in（WLBI）或封裝後在 burn-in 爐中進行，並在其中執行測試圖形（test during burn-in, TDBI）。

最終出貨品質以 DPPM（每百萬顆不良數）衡量，車用產品目標往往在個位數 DPPM 以下。統計方法如 PAT（Part Average Testing）會剔除參數雖在規格內、但明顯偏離同批分佈的離群晶片。可靠度驗證項目見可靠度章節。
