Chapter 5 · Test & packaging

封測：找出壞掉的位元、修好它、再把晶片疊起來

記憶體是測試最密集的半導體產品：每顆晶片的每一個位元都必須被寫入、讀出、在高低溫下驗證；壞的要找出來並修補，修不好的要淘汰。封裝則從單顆晶片走向十幾層的 TSV 堆疊，對已知良好晶粒（KGD）的要求越來越高。

測試流程總覽

  • WAT（Wafer Acceptance Test）：量切割道上的測試結構，確認製程參數在規格內，屬於製程監控。
  • CP（Chip Probe / Wafer Sort）：探針卡接觸每顆晶粒的焊墊，執行直流測試（open/short、漏電、IDD）與功能測試，輸出每顆晶粒的失效位元資料。
  • 修補：依失效位址決定備用列 / 行的配置，用雷射或電熔絲寫入，再重測確認。
  • FT（Final Test）：封裝後在 ATE 上全速測試，依可通過的速度與時序分級（speed binning）。

記憶體故障模型

測試不是隨便寫些資料再讀回來，而是根據可能的物理缺陷抽象出故障模型，再設計能涵蓋它們的測試序列。

CF 耦合型對某個單元（攻擊者）的操作改變了另一單元（受害者）相鄰單元間漏電、電容耦合、橋接

March 演算法

March 測試由多個「March 元素」組成：每個元素依指定的位址順序（⇑ 遞增、⇓ 遞減、⇕ 任意）走過每一個單元，對每個單元依序執行一串操作（w0 寫 0、r1 讀並預期 1……）。複雜度與單元數 N 成線性，適合大容量記憶體。

March C−：{ ⇕(w0); ⇑(r0,w1); ⇑(r1,w0); ⇓(r0,w1); ⇓(r1,w0); ⇕(r0) }　→ 10N

為什麼這樣設計

  • 每個單元都被讀到 0 和 1 → 抓 SAF。
  • 每個單元都經歷 0→1 和 1→0 轉換，並在轉換後被讀 → 抓 TF。
  • 以遞增與遞減兩種順序走訪：對任一對單元，攻擊者總會在某個元素中「先」被操作，然後受害者「後」被讀取 → 抓各種方向的耦合故障。
  • 每個元素都先讀再寫，讀的值是上一個元素寫入的值；若位址解碼錯誤，會讀到不對的值 → 抓 AF。

實務上 DRAM 測試還會加入各種資料背景（全 0、棋盤、列條紋、行條紋）、時序壓力（縮短 tRCD/tWR）、電壓邊界（VDD 高 / 低）、溫度，以及長時間暫停的保存測試。

修補流程與 KGD

  1. CP1 執行完整測試，記錄所有失效位元的位址。
  2. 修補分析（RA）：每個 mat 只有固定數量的備用列 / 行。若某列失效位元數超過備用行數，這列「必須」用備用列修（must-repair）；剩下的再以搜尋演算法分配。找不到解的晶粒判為不可修。
  3. 熔絲寫入：雷射熔絲（雷射燒斷金屬線，需要開窗、只能在晶圓上做）或電熔絲 / 反熔絲（電流熔斷或擊穿，封裝後也能寫）。
  4. CP2 驗證修補結果，並做低溫或保存測試。

KGD（Known Good Die）：要被堆疊或與其他晶片共封裝的晶粒，必須在晶圓階段就達到接近封裝後成品的品質，因為一片壞晶粒會拖累整個昂貴的堆疊。這讓晶圓測試必須涵蓋更多原本在 FT 才做的高速與溫度測試。

ATE 與測試成本

  • 平行度：記憶體 ATE 一次可測數百顆晶粒（CP）或數百顆封裝（FT），由測試機內建的演算法圖形產生器（ALPG）產生位址與資料序列。
  • 測試時間：容量越大、測試時間越長；保存測試需要等待，更是耗時。數十 Gb 晶片的完整測試可達數十分鐘到數小時。
  • 測試成本可達 DRAM 總成本的可觀比例，因此會用：晶片內建自我測試模式（DFT test mode，例如一次寫多個 bank、內部壓縮比較結果）、減少不必要的測試項目、提高平行度。
  • 直流測試：Open/Short（接觸）、輸入漏電、各種 IDD（IDD0 啟動電流、IDD2P 待機、IDD6 自我更新）。
  • 速度分級：同一批晶片依能穩定運作的最高速度與時序分成不同等級出貨。

嵌入式記憶體的 MBIST

SoC 裡的 SRAM 數以百計，無法從外部腳位直接存取。MBIST（Memory Built-In Self-Test）在每組記憶體旁加入控制器，由晶片內部產生 March 序列並比較結果，只把通過 / 失敗與失效位址送出。搭配 BIRA / BISR（內建修補分析 / 自我修補）可以自動配置備用元件，修補資訊存在 e-fuse 中，開機時載入。車用晶片還要求開機或執行期週期性執行 MBIST（in-system test）以符合功能安全。

組裝流程

  1. 晶圓研磨（Back grinding）：把晶圓從約 775 µm 磨薄到數十 µm（多晶粒堆疊需要很薄）。
  2. 切割（Dicing）：刀片切割、雷射開槽或隱形雷射切割（stealth dicing，在晶圓內部形成改質層再擴張分離，適合超薄晶圓）。DBG（先切後磨）可降低薄晶粒的崩邊與破裂。
  3. 黏晶（Die attach）：以晶粒黏著膜（DAF）固定在基板或下層晶粒上。
  4. 打線（Wire bonding）：金線或銅線連接晶粒焊墊與基板，多層堆疊時以階梯錯位或線上膜（FOW）方式打線。
  5. 模封（Molding）：環氧樹脂模封保護。
  6. 植球、雷射打印、切單（Singulation）。

HBM 堆疊與 TSV

  • TSV：在 DRAM 晶粒中蝕刻數千個直徑數 µm 的矽穿孔並填銅（通常在前段與後段之間製作，via-middle），研磨晶圓背面讓 TSV 露出，做背面凸塊。
  • 晶粒減薄：12 層堆疊加上基底晶粒要塞進 JEDEC 規定的封裝高度（HBM3E 為 720 µm，HBM4 放寬到 775 µm），每片核心晶粒只有約 30–50 µm 厚。
  • 堆疊與填充：
    • TC-NCF：每層之間放非導電膜，以熱壓鍵合逐層接合。
    • MR-MUF：先以回流焊一次接合所有層，再注入液態模封材料填滿縫隙，散熱與產能較佳。
    • 混合鍵合（Hybrid bonding）：沒有凸塊，Cu–Cu 直接接合，可縮小層間距與總高度，被視為 16 層以上堆疊的關鍵技術。
  • 測試挑戰：核心晶粒在堆疊前要做 KGD 測試；堆疊後要測 TSV 連通性，並用備用 TSV 修補；基底晶粒提供 IEEE 1500 測試介面與 MBIST。完成的堆疊（KGSD, Known Good Stacked Die）再交給 2.5D 封裝。
  • 散熱與翹曲：多層薄晶粒熱阻高，熱源 GPU 又在旁邊；不同材料的熱膨脹係數不同，會造成翹曲與接點應力。

Burn-in 與最終品質

浴缸曲線告訴我們：早期失效（infant mortality）來自製造中的潛在缺陷。Burn-in 在高溫（例如 125 °C）與高電壓下長時間操作晶片，加速這些弱元件提早失效，在出貨前把它們篩掉。記憶體常以晶圓層級 burn-in（WLBI）或封裝後在 burn-in 爐中進行，並在其中執行測試圖形（test during burn-in, TDBI）。

最終出貨品質以 DPPM（每百萬顆不良數）衡量，車用產品目標往往在個位數 DPPM 以下。統計方法如 PAT（Part Average Testing）會剔除參數雖在規格內、但明顯偏離同批分佈的離群晶片。可靠度驗證項目見可靠度章節。
